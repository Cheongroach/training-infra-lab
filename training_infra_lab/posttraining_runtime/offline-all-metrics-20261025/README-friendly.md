# 全量指标离线页面：使用说明

打开 `index.html` 即可。页面完全离线，保持 `assets/`、`_shared/` 和 `evidence/` 相对路径即可。

## 包含什么

| 数据 | 数量 |
|---|---:|
| 指标序列 | 230 |
| 指标采样点 | 27,064 |
| NSYS 表 | 63 |
| NSYS 原始行 | 827,115 |
| rollout / eval 样本 | 104 |
| 结构化运行事件 | 108 |
| 可浏览数据集 | 71 |

数据来自两个四卡 H20 任务：历史基线 `70d36e11e929c5c3` 和诊断任务 `49b6f8781696e68e`。

## 四个页面

1. **全部指标**：搜索任务、类别、指标和 rank，最多同时选择四条曲线。
2. **NSYS 全部表**：按表和字段搜索，分页查看 82 万行原始数据。
3. **训练与原始数据**：查看 prompt、response、reward、token、log-prob、事件和验收。
4. **来源与下载**：查看每个数据集的行列数、SHA256 和原始文件。

筛选后的 CSV/JSON 导出在浏览器本地完成。

## 数据边界

- NCU 没有命中实际 kernel，因此没有有效硬件计数器；
- CPU 周期和上下文切换采样关闭；
- 没有线上服务 SLO；
- 完整回答协议仍失败；
- profiling 数据用于诊断，不能直接证明性能收益。

原始字段转换、JavaScript 大整数处理和隐私处理见 [完整说明](README.md)。
