# Qwen3.5-9B GRPO：测量报告读者版

## 要回答的三个问题

1. 4×H20 能否执行 Qwen3.5-9B 的真实采样和全参数 GRPO 更新？
2. 生成期间保留聚合后的 FSDP 权重，是否能减少逐 token all-gather？
3. 修复奖励规则后，非零梯度是否真的来自完成的错误答案？

## 固定设置

- 模型：Qwen3.5-9B 文本主干，8,953,803,264 个训练参数；
- 设备：4×H20；
- 参数与归约：FP32；计算：BF16；
- FSDP2、逐 block activation checkpoint、FLA GDN；
- Adam epsilon `1e-4`，FP32 output head；
- MATH 固定子集，每题 4 条回答。

所有 worker 源码与提交 manifest 按 SHA256 核对。设备门禁比较独立全局 batch 与 FSDP 更新，并检查参数、梯度和 Adam 两阶矩。

## 结果一：生成期权重驻留有效

普通 FSDP 在每个生成 token 上重新聚合参数。驻留方案在无梯度生成阶段暂时保留完整 BF16 权重，结束后恢复分片训练状态。

128-token 配对实验使用同一初始参数、随机种子和输入：

| 重复 | 普通 FSDP | 生成期驻留 | 比值 |
|---|---:|---:|---:|
| 1 | 12.345 s | 7.117 s | 1.735× |
| 2 | 12.407 s | 7.038 s | 1.763× |
| 3 | 12.379 s | 7.029 s | 1.761× |

中位比值为 **1.761×**。每卡 all-gather 从 528 次降至 33 次，正好对应 33 个 FSDP group 从“每 token 一次”变为“整个生成阶段一次”。

代价是峰值 allocated 从 16.99 增至 29.44 GiB/卡。这个数字只属于本运行时的生成阶段，不是完整 RL、vLLM 或 verl 的端到端加速。

## 结果二：长度排序没有稳定收益

固定同一批轨迹和 optimizer 状态，比较 verl KK 计划与本地长度排序计划。两种方案的 microbatch 均为 1，各重复三次。

- verl 中位：4.368 s；
- length-sorted 中位：4.392 s；
- 配对中位比值：0.988×。

第一次配对偏向排序方案，但后两次没有保持。当前结论是保留基线，不宣称调度加速。

## v8：执行通过，奖励规则有缺陷

v8 完成 4 次非零梯度更新，共 64 条轨迹。30 条正常结束，34 条达到长度上限。

旧规则读取回答中的最后一个数字。它把 4 条截断回答判为正确；其中一条停在含 `sqrt(21)` 的中间推导，数字 21 恰好等于参考答案。

所以 v8 证明了：

- 真实采样到 FSDP 更新链路可以运行；
- 生成期驻留有可重复的局部收益；
- actor 排序计划没有稳定收益。

v8 没有证明奖励可靠或数学能力改善。

## v9：严格奖励下只有第四步产生学习信号

新规则要求正常 EOS，且最后一行严格为 `Final answer: <number>`。独立审计重新读取原始文本和固定参考答案，不信任训练时保存的 reward。

| 更新 | 回答数 | 正确 | 明确错答 | 格式失败 | 截断 | 非零组 | 梯度范数 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 0 | 16 | 16 | 0 | 0 | 0 | 0 | 0 |
| 1 | 16 | 16 | 0 | 0 | 0 | 0 | 0 |
| 2 | 16 | 16 | 0 | 0 | 0 | 0 | 0 |
| 3 | 16 | 14 | 2 | 0 | 0 | 1 | 0.915452 |

两条错误回答来自同一道题。模型把正确的因式分解常数 125 写成 149，最终回答 141；同组另两条回答 13，形成了组内 reward 差异。

第四步后，Adam `exp_avg` 和 `exp_avg_sq` 各有 7,935,924,616 个非零元素。前三步两者均为零。

这证明完成的错误答案可以通过严格奖励进入一次真实更新。它没有证明下一步正确使用非零动量，也没有证明训练后的能力提高。

## 正确的结论强度

| 结论 | 是否支持 |
|---|---|
| 4×H20 可执行 9B 同步 GRPO 链路 | 支持 |
| 生成期驻留减少本运行时 all-gather 和生成时间 | 支持 |
| 长度排序比 KK 更快 | 不支持 |
| 严格奖励能区分完成错答与截断 | 支持 |
| v9 完成四次非零梯度更新 | 不支持；仅第四次非零 |
| 数学能力提高 | 未测 |
| 910B4 已完成适配 | 未完成 |
